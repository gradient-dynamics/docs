Studio#

Gradient Dynamics Studio is the GUI interface to Gradient Dynamics simulation technology. It brings project setup, geometry review, meshing, solver configuration, run monitoring, and post-processing into one browser workspace.

Workspace Areas#

Area

Purpose

Dashboard

Create projects, review recent work, and track run status.

3D Viewer

Inspect geometry, domains, surfaces, meshes, and results.

Setup Panel

Configure domains, physics, materials, boundary conditions, and run controls.

Feature Tree

Navigate geometry, regions, zones, named surfaces, simulations, and results.

Logs and Monitors

Follow meshing and simulation progress with live status updates.

Post-Processing

Visualize fields, slices, streamlines, probes, forces, moments, and heat-transfer quantities.

Core Workflows#

Geometry Preparation#

Upload CAD or surface files, check geometry health, repair common issues, and define named surfaces for boundary conditions.

Meshing#

Studio supports two meshing types:

Mesh Type

Use When

Structured

You want an automated, robust mesh workflow with predictable controls for common CFD and multiphysics cases.

Unstructured

You need flexibility for complex geometry, interoperability, or imported-mesh workflows.

Simulation#

Configure physics, materials, boundary conditions, turbulence models, run controls, and convergence targets. Studio keeps the solver setup user-facing so you can focus on engineering intent rather than implementation details.

Results#

Inspect convergence, visualize scalar and vector fields, compute engineering quantities, and compare runs within the same project.
