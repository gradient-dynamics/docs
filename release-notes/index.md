# Release notes

Product changes across Studio, meshing and FluxCore are collected here. Release
notes focus on changes that affect engineering workflows, compatibility or
results.

## August 2026

### Documentation preview

- Introduced the Furo-based documentation experience.
- Added task-oriented User Guide and Studio sections.
- Published the first preview of the API resource model and service contracts.
- Added NACA 0012 aerodynamic and plate-fin heat-sink CHT validation studies.

### Studio

- Expanded project workspaces for shared geometry, meshes, simulations and
  results.
- Improved organisation-level visibility of GPU usage and storage.
- Consolidated preprocessing, meshing, run monitoring and post-processing into
  a single browser workflow.

## Release-note policy

Dates refer to the first general availability of a change unless the entry is
marked **Preview**. Preview capabilities can change before public release. For
questions about availability in your organisation, contact Gradient Dynamics.
