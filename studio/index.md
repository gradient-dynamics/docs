# Studio

Gradient Dynamics Studio is the browser-based workspace for preprocessing,
meshing, simulation and post-processing. It gives engineering teams access to
FluxCore compute without requiring a local solver installation or GPU cluster.

<div class="api-status">One workspace · geometry to results</div>

## What you can do

::::{grid} 1 2 2 2
:gutter: 3

:::{grid-item-card} Prepare
Import CAD or surfaces, inspect scale and orientation, define domains, regions
and named boundaries, and repair common geometry issues.
:::

:::{grid-item-card} Mesh
Build prism–octree meshes with automatic surface preparation, target cell
counts, local refinement and near-wall controls.
:::

:::{grid-item-card} Simulate
Configure fluid and thermal physics, materials, rotating regions, boundary
conditions, run controls and engineering outputs for FluxCore.
:::

:::{grid-item-card} Understand
Monitor runs, inspect fields, create slices and streamlines, probe values,
compute forces and heat-transfer quantities, and compare revisions.
:::

::::

## Built for teams

Projects keep geometry, meshes, simulations, logs and results together.
Organisations can invite members, assign roles, share projects, review storage
and track GPU usage from the same browser workspace.
