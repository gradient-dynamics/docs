# Studio

Gradient Dynamics Studio is the GUI interface to Gradient Dynamics simulation technology. It brings project setup, geometry review, meshing, solver configuration, run monitoring, and post-processing into one browser workspace.

## Workspace Areas

| Area | Purpose |
|------|---------|
| **Dashboard** | Create projects, review recent work, and track run status. |
| **3D Viewer** | Inspect geometry, domains, surfaces, meshes, and results. |
| **Setup Panel** | Configure domains, physics, materials, boundary conditions, and run controls. |
| **Feature Tree** | Navigate geometry, regions, zones, named surfaces, simulations, and results. |
| **Logs and Monitors** | Follow meshing and simulation progress with live status updates. |
| **Post-Processing** | Visualize fields, slices, streamlines, probes, forces, moments, and heat-transfer quantities. |

## Core Workflows

### Geometry Preparation

Upload CAD or surface files, check geometry health, repair common issues, and define named surfaces for boundary conditions.

### Meshing

Studio supports two meshing types:

| Mesh Type | Use When |
|-----------|----------|
| **Unstructured** | You want the recommended starting point for production CFD, boundary-layer workflows, complex geometry, interoperability, or imported meshes. |
| **Structured** | You want an automated, repeatable mesh workflow where a structured approach fits the solver and validation target. |

### Simulation

Configure physics, materials, boundary conditions, turbulence models, run controls, and convergence targets. Studio keeps the solver setup user-facing so you can focus on engineering intent.

### Results

Inspect convergence, visualize scalar and vector fields, compute engineering quantities, and compare runs within the same project.
